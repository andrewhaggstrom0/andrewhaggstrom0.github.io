Surgical VLM Temporal Benchmark

ML CV DINOv2 / CLIP EndoViT PyTorch Cholec80 HF Transformers SLURM
View on GitHub → Read the Paper (PDF) →

A reproducible benchmark showing that frame-level accuracy — the standard way frozen vision foundation models are compared for surgical video — overstates the value of surgical-domain pretraining, because temporal aggregation recovers most of the same advantage for free. I benchmarked four vision foundation models (DINOv2, CLIP, EndoViT, BiomedCLIP) on laparoscopic surgical phase recognition using Cholec80, spanning the pretraining 2×2 of general-vs-medical and self-supervised-vs-language-supervised. Using paired video-level statistics over all 80 videos, I found that the large advantage surgical-domain pretraining shows on frame-level probing largely disappears once you apply the temporal smoothing any deployed system uses — and that the effect is specific to the domain-pretrained encoder, not a generic artifact of smoothing.

Motivation

Frozen foundation-model features are the default perception backbone for surgical video systems, and groups increasingly pay for surgical-domain pretraining on the strength of frame-level benchmark numbers. But a deployed system reasons over an ordered stream and aggregates across it, while the standard evaluation grades encoders on independently sampled, scrambled frames — discarding the very temporal structure the system operates on. Whether a frame-level ranking survives the temporal aggregation a real system performs, and whether domain pretraining's benefit is temporal-recoverable, was unmeasured. That gap is what this project addresses.

Approach

  • Extract frozen embeddings once through a uniform encoder interface, then run every experiment as a pure function over that cache
  • Store embeddings as memory-mapped NumPy arrays verified by SHA-256 manifest on every read
  • Use video-level splits throughout — frames within a surgery are near-duplicates, so frame-level splitting leaks and frame-level error bars are an order of magnitude too tight
  • Run linear and kNN probes, plus a temporal-reliability suite validated against twelve synthetic controls
  • Sweep a majority-filter smoothing in both offline and real-time (causal) variants
  • Test cross-encoder claims with a paired video-level bootstrap under 5-fold cross-validation over all 80 videos

Findings

  • The advantage evaporates: EndoViT leads general-purpose DINOv2 by 6.0 accuracy points on the frame-level probe, but 85% of that lead disappears under causal temporal smoothing, leaving a residual gap indistinguishable from zero
  • Specific, not generic: every EndoViT gap shrinks 55–85% under smoothing while the DINOv2–CLIP gap is flat (1%), ruling out generic compression and localizing the effect to domain pretraining
  • Supervision beats domain: medical pretraining delivered by language supervision (BiomedCLIP) transfers essentially nothing over general CLIP in accuracy, though it does change how the representation tracks scene motion
  • Systematic over-segmentation: all four encoders predict 80–124× too many phase transitions at 0.66–0.72 frame accuracy

The Core Result

Frame-level evaluation systematically overstates what surgical-domain pretraining buys, because temporal aggregation substitutes for much of it — a negative result with teeth, independently corroborated by concurrent work showing EndoViT's advantage reverses out-of-domain under a stronger temporal head. It is backed by paired video-level statistics, a specificity control, a well-powered null, a variance-normalized drift metric (raw drift is gameable by low-variance encoders, and correcting it changes the stability ranking), and a candid methodological note: an apparent rank inversion I found at n=32 failed to replicate at n=80 — itself evidence that the sub-2-point encoder margins common in this literature aren't resolvable without paired error bars.

Stack

Python · PyTorch · Hugging Face Transformers · timm · open_clip · scikit-learn · NumPy · SciPy · OpenCV · Hydra · pytest · matplotlib · SLURM · CUDA · LaTeX. Frozen embeddings are extracted once and cached as memory-mapped arrays with SHA-256 manifests; downstream probes, the temporal-reliability suite, dense optical-flow coupling (OpenCV Farneback), and the paired video-level bootstrap all run as pure functions over that cache, on a WashU A40 SLURM cluster.
