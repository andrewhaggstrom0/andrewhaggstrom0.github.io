Geometry-Token VLA Robustness

Robotics ML OpenVLA-OFT PointNet PyTorch LIBERO-Plus MuJoCo HF Transformers
View on GitHub → Read the Paper (PDF) →

How much manipulation robustness can the cheapest possible geometric prior buy? I injected a single geometry token — free simulator depth, converted to a world-frame point cloud and encoded by a ~18M-parameter PointNet — into the 7B OpenVLA-OFT policy, then measured per-axis robustness across the 2,519 perturbed tasks of the LIBERO-Plus benchmark.

Motivation

Vision-Language-Action (VLA) models achieve near-perfect success on clean manipulation benchmarks but degrade sharply once the camera moves or the robot starts from an unfamiliar pose. The literature leaves a cost-focused question open: rather than adding expensive sensing or large 3D backbones, how far does the single cheapest geometric signal go toward closing that robustness gap?

Approach

  • Performed model surgery on OpenVLA-OFT (7B) to inject one PointNet-encoded geometry token alongside the existing vision-language tokens
  • Built a custom data pipeline converting free simulator depth into world-frame point clouds for encoding
  • Trained with a literature-backed frozen-component recipe, keeping the backbone fixed while adapting the injection path
  • Evaluated per-perturbation-axis on LIBERO-Plus (2,519 perturbed tasks) to isolate where robustness actually breaks

Findings

  • Fragility fingerprint: the base model collapses selectively on geometric axes (Camera Viewpoints 45.8%, Robot Initial States 34.6%) while appearance axes hold firm (Background 82.0%, Language 96.3%)
  • Verified injection architecture: the end-to-end surgery, data pipeline, and training recipe produced a policy with converged offline behavior (mean action L1 error 0.036–0.074) and restored gripper anticipation
  • Systems post-mortem: documented five distinct failure modes — four silent train/eval configuration mismatches and one deeper offline-to-closed-loop generalization gap — plus the diagnostic instruments built to isolate each

The Core Result

The headline finding is a concrete demonstration of compounding covariate shift in narrow-data VLA fine-tuning: a policy can predict its own training data nearly perfectly while scoring 0% in closed-loop rollouts, even on unperturbed scenes. Offline action accuracy is a dangerously optimistic proxy for closed-loop competence, and this project quantifies exactly how wide that gap can open.

Stack

PyTorch, OpenVLA-OFT, PointNet, HuggingFace Transformers, LIBERO / LIBERO-Plus, robosuite + MuJoCo, Open3D, NumPy, CUDA.
