LfD Manipulation Pipeline

Robotics ROS2 Imitation Learning

Learning from Demonstration for a 6-DOF arm using ACT. Achieved 82% success rate on unseen pick-and-place tasks.

Overview

This project implements an end-to-end Learning from Demonstration pipeline for robotic manipulation. Human demonstrations are collected via teleoperation and used to train an Action Chunking with Transformers (ACT) policy that generalizes to novel object arrangements.

Key Features

  • Teleoperation data collection with a leader-follower arm setup
  • ACT policy with visual observations from wrist and overhead cameras
  • ROS2 integration for real-time control at 10 Hz
  • Generalization to unseen object positions and lighting conditions

Results

Trained on 50 demonstrations, the policy achieves an 82% success rate on novel pick-and-place configurations, with graceful degradation under moderate visual perturbations.
